# KilysCommerce

## Description
KilysCommerce est un projet de commerce électronique.

## Fonctionnalités
- Gestion des produits
- Gestion des commandes
- Interface utilisateur moderne

## Installation
```bash
# Cloner le dépôt
git clone https://github.com/votre-username/kilyscommerce.git

# Installer les dépendances
cd kilyscommerce
npm install
```

## Utilisation
```bash
npm start
```
